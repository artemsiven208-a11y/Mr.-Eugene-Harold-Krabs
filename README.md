# Telegram-бот для конвертации файлов

Бот принимает документ, изображение, таблицу, аудио или видео в Telegram, определяет исходный формат и показывает только подходящие направления конвертации. После выбора он выполняет преобразование локальными библиотеками и отправляет результат обратно в чат.

## Возможности

- определение формата по расширению, MIME-типу и сигнатуре файла;
- обработка документов, таблиц, изображений, PDF и медиа;
- динамические кнопки только для доступных конвертеров;
- поиск формата по тексту и исправление простых опечаток;
- отдельный временный каталог для каждого задания;
- ограничение размера файла, времени и количества одновременных тяжёлых операций;
- понятные сообщения об ошибках и журналирование без содержимого пользовательских файлов;
- повторная конвертация исходного файла в другой формат до завершения задания.

## Поддерживаемые форматы

Ниже перечислены направления, которые работают без внешних программ. Направления через LibreOffice и FFmpeg появляются в меню только при обнаружении соответствующей программы.

| Исходный формат | Доступные форматы | Инструмент |
|---|---|---|
| PNG, JPG/JPEG, WEBP, BMP, TIFF, GIF | PNG, JPG, JPEG, WEBP, BMP, TIFF, GIF, PDF | Pillow |
| PDF | TXT, PNG, JPG | PyMuPDF |
| TXT | PDF, HTML | PyMuPDF / Python |
| MD | HTML, PDF | Python / PyMuPDF |
| DOCX | PDF, TXT, HTML | python-docx / PyMuPDF |
| RTF | TXT, PDF | Python / PyMuPDF |
| CSV | XLSX | openpyxl |
| XLSX | CSV | openpyxl |
| DOC, ODT, DOCX, RTF | PDF, DOCX* | LibreOffice |
| HTML | TXT, PDF | Python / LibreOffice* |
| PDF | DOCX* | LibreOffice |
| XLS, ODS, XLSX | PDF, XLSX* | LibreOffice |
| PPT, PPTX, ODP | PDF, PPTX* | LibreOffice |
| MP3, WAV, OGG, FLAC, M4A | другой аудиоформат | FFmpeg |
| MP4, WEBM, MOV, MKV | другой видеоформат или MP3 | FFmpeg |

Звёздочкой отмечены направления, зависящие от конкретной версии LibreOffice и исходного документа. При нескольких страницах PDF результатом преобразования в изображения становится ZIP-архив.

## Требования

- Python 3.11 или новее;
- токен Telegram-бота от BotFather;
- LibreOffice нужен для офисных документов, таблиц и презентаций;
- FFmpeg нужен для аудио и видео.

Изображения, PDF, TXT, MD, DOCX, RTF и CSV/XLSX работают без LibreOffice и FFmpeg. Для DOCX → PDF без LibreOffice сохраняются текст и таблицы, а сложное форматирование упрощается. После установки LibreOffice становятся доступны точные офисные направления DOC/DOCX/ODT, XLS/XLSX/ODS и PPT/PPTX/ODP. FFmpeg добавляет аудио- и видеоконвертацию.

## Установка на Windows

1. Установите Python 3.11+ и откройте PowerShell.
2. Скачайте проект и перейдите в его каталог.
3. Создайте виртуальное окружение:

   ```powershell
   py -3 -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```

4. Установите зависимости:

   ```powershell
   python -m pip install --upgrade pip
   pip install -r requirements.txt
   ```

5. Установите внешние конвертеры:

   ```powershell
   winget install --id TheDocumentFoundation.LibreOffice --accept-source-agreements --accept-package-agreements
   winget install --id Gyan.FFmpeg --accept-source-agreements --accept-package-agreements
   ```

   После установки перезапустите PowerShell, чтобы обновился `PATH`. Бот также проверяет стандартный путь LibreOffice в `C:\Program Files\LibreOffice\program\soffice.exe`.

6. Скопируйте `.env.example` в `.env` и укажите токен:

   ```powershell
   Copy-Item .env.example .env
   notepad .env
   ```

7. Запустите бота:

   ```powershell
   python main.py
   ```

## Установка на Linux

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
sudo apt update
sudo apt install -y libreoffice ffmpeg
cp .env.example .env
python main.py
```

LibreOffice и FFmpeg устанавливаются средствами дистрибутива. Их пути можно явно задать в `.env` через `LIBREOFFICE_PATH` и `FFMPEG_PATH`.

## Использование

1. Отправьте или перешлите файл боту.
2. Выберите целевой формат кнопкой либо нажмите «Другой формат» и введите расширение.
3. Дождитесь результата и при необходимости выберите следующий формат для того же исходного файла.

Примеры: Word → PDF при установленном LibreOffice, PDF → изображения, PNG → WEBP, Excel → CSV, TXT → PDF с русским текстом.

## Команды

- `/start` — приветствие и краткая инструкция;
- `/help` — как отправить и конвертировать файл;
- `/formats` — направления, доступные в текущей среде;
- `/cancel` — удалить текущую операцию и временные файлы.

Команды регистрируются в меню Telegram при запуске.

## Структура проекта

```text
main.py                 запуск long polling
bot/                    Telegram-обработчики, клавиатуры и состояния
converters/             обработчики форматов и единый реестр направлений

tests/                  автоматизированные локальные проверки
requirements.txt        зависимости Python
.env.example            пример настроек
```

## Настройка и ограничения

Параметры `.env`:

- `BOT_TOKEN` — обязательный токен;
- `MAX_FILE_SIZE_MB` — максимальный размер загружаемого файла, по умолчанию 20 МБ;
- `MAX_CONCURRENT_JOBS` — число одновременных конвертаций, по умолчанию 3;
- `TEMP_FILE_TTL_MINUTES` — срок хранения аварийно оставшихся каталогов;
- `CONVERSION_TIMEOUT_SECONDS` — ограничение времени одной операции;
- `LIBREOFFICE_PATH`, `FFMPEG_PATH` — необязательные явные пути к программам.

Telegram ограничивает размер файлов способом загрузки, а преобразование PDF обратно в редактируемый DOCX может потерять структуру и форматирование. OCR в проекте не реализован: для PDF-сканов бот предупредит, что обычный текст не найден. GIF при преобразовании в неподвижное изображение сохраняет первый кадр. HTML не исполняется как код.

## Типичные ошибки

- **Не указан токен.** Создайте `.env` и заполните `BOT_TOKEN`.
- **Не найден LibreOffice.** Установите его или используйте направления, не требующие офисного конвертера.
- **Не установлен FFmpeg.** Аудио и видео будут недоступны, остальные функции продолжат работать.
- **Не удалось скачать файл.** Проверьте соединение с Telegram и отправьте файл повторно.
- **Ошибка установки зависимостей.** Обновите pip внутри виртуального окружения и повторите `pip install -r requirements.txt`.

## Проверка

Локальные тесты запускаются командой:

```powershell
pytest -q
```

Проверяется синтаксис, определение формата, поиск с опечаткой, реальные преобразования TXT → PDF, PDF → TXT, PNG → JPG с прозрачностью, JPG → WEBP, CSV/XLSX и недоступные направления. Проверка Telegram API требует настоящего токена и в локальные тесты не входит.
